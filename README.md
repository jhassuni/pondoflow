# Pondo Flow

**Offline double-entry bookkeeping: funds, projects, bills and budgets.**

Pondo Flow is a bookkeeping app for people who handle real money — a household, a small organisation, a church or a
community project. Everything stays on your phone: no account, no sign-in, no ads, no tracking, and the app has no
internet access at all.

- Funds and projects · double-entry ledger · bills to pay and to collect (incl. repeating bills)
- Budgets with budget vs actual · reports you can tap into · charts · project statement
- Receipt photos · backup & restore · audit log · app lock and privacy mode
- 10 languages

**Status:** testing on Google Play (link coming soon). A [sigbin.net](https://sigbin.net) app.

## Report a bug or suggest an idea
Open an issue with the **Bug report** or **Feature idea** form: [New issue](../../issues/new/choose).
Please **never post real amounts, names or account numbers** — use made-up examples.
Security problems: please report them privately — see [SECURITY.md](SECURITY.md).

This repository holds the app's public documentation and its public issue tracker; the source code is private.
