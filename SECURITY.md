# Reporting a security problem

If you find a way to read, change or unlock someone's books without permission, or any other security problem,
**please do not open a public issue.** Report it privately instead:
**[Report a vulnerability](https://github.com/jhassuni/pondoflow/security/advisories/new)** (GitHub keeps it visible
only to you and the maintainers). Include the steps to reproduce it. We will answer within a few days and credit you
(if you wish) once it is fixed.
